# محرر — منظومة وكلاء مستقلة باستخدام OpenAI Agents SDK

هذه النسخة ليست سلسلة مطالبات JavaScript. الخادم يستخدم حزمة `openai-agents` فعلياً، ويعرّف تسعة كائنات `Agent` مستقلة:

1. محلل الطلب.
2. مدقق الموثوقية.
3. خبير الشكليات المغربية.
4. المراجع القانوني.
5. المحرر الإداري.
6. المدقق اللغوي والأسلوبي.
7. مراقب الجودة.
8. وكيل التصحيح.
9. وكيل التسليم النهائي.

المراحل الست الأولى منسقة برمجياً لضمان عدم تخطي أي مراجعة. بعد ذلك تبدأ حلقة مستقلة تعتمد handoffs أصلية في SDK:

`مراقب الجودة → وكيل التصحيح → مراقب الجودة` عند وجود عيوب، أو `مراقب الجودة → وكيل التسليم النهائي` عند الاعتماد.

يستخدم النظام كذلك:

- `Runner.run` لتنفيذ الوكلاء.
- `OpenAIProvider` بمفتاح يرسله الهاتف لكل تشغيل.
- `SQLiteSession` لحالة الجلسة.
- `trace` لتتبع العملية.
- `function_tool` لأدوات القياس واستخراج مواضع الاستكمال وفحص الادعاءات الحساسة.
- مخرجات Pydantic منظمة للوكلاء التخصصيين.

## لماذا يوجد خادم؟

Agents SDK الخاص بـPython لا يعمل داخل ملف HTML على الهاتف. الهاتف يشغل واجهة PWA، بينما ينفذ الخادم الوكلاء. يمكن نشر المشروع على أي استضافة Docker ثم فتح الرابط من الهاتف وتثبيته على الشاشة الرئيسية.

المفتاح يحفظ اختيارياً في `localStorage` داخل هاتفك، ويرسل عبر HTTPS في ترويسة `X-OpenAI-Key`. لا يكتبه الخادم في قاعدة البيانات أو ملفات البيئة.

## التشغيل محلياً

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## النشر من الهاتف

1. ارفع محتويات المشروع إلى مستودع GitHub خاص.
2. أنشئ Web Service من المستودع في خدمة تدعم Docker، أو استخدم ملف `render.yaml`.
3. بعد اكتمال النشر، افتح رابط HTTPS من الهاتف.
4. في Android اختر «تثبيت التطبيق». في Safari على iPhone اختر «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».
5. أدخل مفتاحك داخل شاشة التطبيق.

## القيود

- يلزم اتصال بالإنترنت.
- PDF المصور بلا طبقة نصية لا يخضع لـOCR.
- استخدام المفتاح من واجهة شخصية يظل أقل أماناً من تخزينه كسر في الخادم، رغم أن الخادم هنا لا يحتفظ به.
- لم يُنفذ اختبار API حي ضمن حزمة التسليم لعدم توافر مفتاح المستخدم في بيئة البناء.
