# محرر Android v4

تطبيق Android أصلي لتحرير الوثائق الإدارية المغربية بواسطة عشرة وكلاء ذكاء اصطناعي يعملون في عشر عمليات Android مستقلة، إضافة إلى ناقل رسائل محايد.

## ما تغير في الإصدار 4

- واجهة عربية منظمة إلى أقسام واضحة: الاتصال، نوع الوثيقة، النموذج، التعليمات، المرفقات، التنفيذ، والنتيجة.
- قوائم مرتبة لأنواع الوثائق: المراسلات والأجوبة، المذكرات والدوريات، التقارير، المحاضر، المشاريع التنظيمية، والعروض والوثائق المؤسساتية.
- قائمة نماذج OpenAI مرتبة بحسب الجودة والكلفة، مع اختيار جهد الاستدلال.
- خزنة مفتاح جديدة تعتمد Android Keystore وAtomicFile داخل ContentProvider غير مُصدّر.
- تحقق فعلي من وصول وكيل المنسق، في عمليته المستقلة، إلى المفتاح قبل بدء الجلسة.
- عرض حالة التنفيذ بصورة مختصرة، مع سجل handoffs قابل للإظهار والإخفاء.
- نسخ النتيجة ومشاركتها من داخل التطبيق.
- إيقاف الجلسة الجارية.

## بنية الوكلاء

1. منسق الوكلاء.
2. محلل الطلب.
3. مدقق الموثوقية.
4. خبير الشكليات المغربية.
5. المراجع القانوني.
6. المحرر الإداري.
7. المدقق اللغوي والأسلوبي.
8. مراقب الجودة.
9. وكيل التصحيح.
10. وكيل التسليم.

لكل وكيل عملية Android وذاكرة SQLite وعميل Responses API وحلقة أدوات مستقلة. تتم التحويلات عبر رسائل موثقة، ولا يستدعي ناقل الرسائل النموذج ولا يحرر المحتوى.

## الخصوصية

يتصل التطبيق مباشرة بواجهة OpenAI Responses API. لا يحتوي المستودع أو ملف APK على مفتاح API. يُخزّن المفتاح محلياً مشفراً، ولا تبدأ الجلسة حتى ينجح اختبار الوصول إليه من عملية وكيل المنسق.

## البناء

يُعاد تركيب المصدر من الأجزاء `android-v4.part00` إلى `android-v4.part07`. يتحقق GitHub Actions من بصمة كل جزء وبصمة الأرشيف الكامل، ثم يشغّل عقد المعمارية ويبني APK ويفحص بنيته قبل رفعه كأثر بناء.
