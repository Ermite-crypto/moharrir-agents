# محرر Android — منظومة وكلاء مستقلة

تطبيق Android أصلي يتصل مباشرة بواجهة OpenAI Responses API من الهاتف، دون خادم وسيط.

## البنية الوكيلة

التطبيق يعرّف تسعة وكلاء مستقلين، لكل وكيل هوية وتعليمات واستدعاء API منفصل:

1. محلل الطلب.
2. مدقق الموثوقية.
3. خبير الشكليات المغربية.
4. المراجع القانوني.
5. المحرر الإداري.
6. المدقق اللغوي والأسلوبي.
7. مراقب الجودة.
8. وكيل التصحيح.
9. وكيل التسليم النهائي.

مراقب الجودة يقرر تحويل التحكم إلى وكيل التصحيح أو وكيل التسليم. تعاد الوثيقة من وكيل التصحيح إلى مراقب الجودة، مع حد أقصى لثلاث دورات. يحتفظ التطبيق بسجل استدعاءات الوكلاء والتحويلات ومدد التنفيذ.

## الخصائص

- إدخال مفتاح OpenAI داخل التطبيق.
- حفظ اختياري مشفر بواسطة Android Keystore.
- قراءة TXT وMD وDOCX وPDF.
- إرسال الصور كمدخلات بصرية.
- نماذج قابلة للاختيار.
- تصدير النتيجة إلى TXT ونسخها.
- لا يرسل المفتاح إلى أي خادم وسيط.

## بناء APK

يُبنى التطبيق تلقائياً بواسطة GitHub Actions من workflow:

`.github/workflows/build-android-apk.yml`

الملف الناتج: `app-debug.apk`.

## ملاحظة أمنية

الاتصال المباشر من تطبيق الهاتف يعني أن المفتاح موجود على الجهاز أثناء الاستخدام. التخزين المحلي مشفر، لكن أي جهاز مخترق أو معدل بصلاحيات مرتفعة قد يستخرج المفتاح.
